# Guia do Chefe — atualizações

Atualizadores do **Guia do Chefe** (programa instalado / pendrive) do GEMAR Atalaias do Sul 313/RS.

## ⬇️ Baixar o atualizador (sempre a versão mais nova)

**[Atualizar-Guia-do-Chefe.exe](https://raw.githubusercontent.com/segprofab-sudo/guia-do-chefe-atualizacoes/main/Atualizar-Guia-do-Chefe.exe)** — versão atual: **1.25.3** (cerca de 10 MB)

1. Baixe o arquivo acima.
2. Dê dois cliques. Ele acha o Guia do Chefe instalado, fecha o programa com segurança (salvando os dados) e troca só os arquivos do programa.
3. Dados, usuários, senhas e backups continuam como estão. Se algo falhar, ele volta sozinho para a versão anterior.

- Serve para qualquer instalação a partir da **1.9.7**, inclusive no pendrive (escolha a pasta do programa).
- Se o Windows avisar "o Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o arquivo não tem assinatura digital paga).
- Computador novo (sem o Guia do Chefe) usa o instalador completo.
- Versões anteriores: pasta [`versoes/`](versoes/).

## Atualização automática

Com internet, o próprio programa avisa quando há versão nova (pé do menu → **Versão** → **Baixar e atualizar**),
baixa daqui e confere o arquivo pelo SHA-256 publicado no [`versao.json`](versao.json) antes de abrir.

Este repositório guarda **somente** os atualizadores e o `versao.json`. Não há código-fonte, dados do grupo nem senhas aqui.
