# Guia do Chefe — atualizações

Atualizadores do **Guia do Chefe** (programa instalado / pendrive) do GEMAR Atalaias do Sul 313/RS.

Este repositório guarda **somente** os arquivos de atualização publicados (em *Releases*) e o `versao.json`
que o programa consulta para saber se há versão nova. Não há código-fonte, dados do grupo nem senhas aqui.

- Versão atual: veja `versao.json` ou a última *Release*.
- Para atualizar: no programa, clique em **Versão** no pé do menu → **Baixar e atualizar**,
  ou baixe o `Atualizar Guia do Chefe X.exe` da última Release e dê dois cliques.
- Serve para qualquer instalação a partir da 1.9.7. Computador novo usa o instalador completo.
- O programa confere o arquivo baixado pelo SHA-256 publicado no `versao.json` antes de abrir.
